# Crawler.Like.Audio

A folder-and-file crawler with a set of conversion utilities around it, shipped as
**two halves in one repo**:

| Half | What it is | Entry |
| :--- | :--- | :--- |
| **`Thin/`** | The browser app — Next.js 16 static export (`output: "export"` → `Thin/out/`), TypeScript, WebAssembly. Runs client-side; deployed to `crawler.like.audio`. | `cd Thin && npm run dev` |
| **`Thick/`** | The desktop app — Python 3 + Tkinter, twelve notebook tabs (`Thick/src/gui_module.py`), settings and history in `Thick/src/config.ini`. | `Thick/run_crawler.sh` (or `python3 Thick/main.py`) |

Inside APK.audio it sits as a submodule of `SCANALYZER.Like.audio` (`01_CAPTURES/CAPTURE.crawler`
files it under the Scanalyzer's capture stage).

## 🚀 Thin — the browser suite, page by page

Fifteen views, grouped in the sidebar (`Thin/src/components/layout/Sidebar.tsx`) as
*Local Folder and File Crawler* (File Crawler, Visual Explorer, Program Map, SCOPE Map,
Project Audit, Extractor, Regenerate), *Web & Generation* (Web Scraper), *Physical*
(Hardware Auditor, Network Sweeper), *Data Conversion* (PDF to MD, CSV Importer & Shuffler,
JSON Importer & Shuffler, Spreadsheet Converter) and *Media Conversion* (Audio Converter).
Two more views exist in code but have no sidebar entry: `JsonConverterView` and
`JsonPrettyPrintView`.

### 1. 🔍 File Crawler
The core engine of the suite. It uses the modern **File System Access API** to read local directories directly in your browser.
* **Pre-Scan Discovery:** When you select a target folder, the crawler instantly performs a lightning-fast pre-scan. It recursively streams over your files to count extensions and calculate byte sizes, grouping them into categories (`PROGRAMMING`, `WEB & MARKUP`, `DATA & CONFIG`, `DOCS`).
* **Selective Crawling:** You are presented with a real-time pie chart of your codebase. You can selectively check or uncheck specific file extensions to include or exclude them from the deep scan.
* **Deep Crawl:** Once configured, the deep crawl extracts the full text of the selected files, runs AST parsing (Abstract Syntax Tree) on supported languages (like Python) using WebAssembly, and compiles everything into a massive `EVERYTHING.LOG` scrape file and a `MAP.txt` directory tree.

### 2. 🔀 Visual Explorer
A highly interactive, drag-and-drop node graph built with **React Flow**.
* It takes the directory structure and AST metrics generated by the **File Crawler** and renders them as a visual dependency graph.
* You can visually explore your codebase architecture, seeing exactly how folders connect to files, and how files connect to specific classes and functions.

### 3. 🌳 Program Map
A dedicated view for analyzing the structural skeleton of your project.
* It displays the pure, text-based directory tree (similar to the Linux `tree` command) generated during the deep crawl.
* Perfect for getting a quick, high-level overview of where everything is located without the visual noise of the full file contents.

### 4. 🔲 SCOPE Map (Project Scope Analyzer)
An interactive, heavily-dense Treemap visualization (powered by `d3-hierarchy`).
* Inspired directly by WinDirStat, it features beautiful 3D radial-gradient "cushions" that perfectly pack the screen.
* Allows you to instantly visualize your project's storage footprint by file size, color-coded vividly by file type or as a heatmap.

### 5. 🛡️ Project Audit
A client-side security and architecture analysis tool. 
* **Secrets Scanner:** Deep-scans your crawled codebase for exposed API keys, passwords, cryptographic tokens, and rogue `.env` variables using advanced regex heuristics.
* **Endpoint Extractor:** Rips through your code to find and extract all hardcoded URLs, IP addresses, and API endpoints, helping you map out your app's external network dependencies.

### 6. 🖲️ Hardware Auditor
Hooks deeply into the browser's native hardware APIs to act as a complete physical peripheral scanner:
* **WebUSB API:** Discovers and authorizes connected USB devices.
* **Web Bluetooth (BLE):** Radar sweeps for nearby Bluetooth Low Energy devices, beacons, and Smart TVs.
* **Web Serial API:** Hunts for connected RS-232 devices, Arduinos, and industrial COM ports.
* **Media Devices (WebRTC):** Silently indexes every camera, microphone, and audio output connected to the system.

### 7. 📡 Network Sweeper
A clever browser-based LAN scanner.
* **Timing Attacks:** Since browsers cannot open raw TCP/UDP sockets, this tool maps out your local network (e.g., `192.168.1.x`) by performing cross-origin HTTP fetches to local IPs. 
* **Heuristic Discovery:** By measuring the exact timeout and connection refused response times (timing attacks), it heuristically determines if a router, IoT device, or local web server exists at a given IP address—**100% inside the browser sandbox**.

### 8. 🌐 Web Scraper
A lightweight utility for converting websites to text.
* Enter any public URL, and the scraper will fetch the raw HTML **through the public
  `api.allorigins.win` CORS proxy** (`WebCrawlerView.tsx`) — the one page whose request
  leaves the browser for a third party: the proxy sees every URL you scrape.
* It then uses client-side parsing (Turndown) to strip away the noise and convert the webpage directly into clean, readable Markdown.

### 9. 📝 Extractor
Shows the text the File Crawler's deep crawl extracted (`extractorText` in the Zustand store)
and downloads it as `Extraction_<date>.md`.

### 10. 📄 PDF to MD
A local document extraction tool.
* Drag and drop any PDF file directly into the browser.
* Using a WebAssembly port of `pdfjs-dist`, it locally extracts all text strings from the document and formats them into Markdown.
* **Privacy First:** Because it runs entirely in Wasm, your sensitive PDFs are never uploaded to any cloud server.

### 11. 📊 Data Converters (CSV / JSON / Spreadsheet)
A powerful suite of data ingestion and shuffling utilities built with `papaparse` and `xlsx` (SheetJS).
* **CSV & JSON Importer/Shuffler:** Flatten or nest massive JSON objects, randomize CSV columns, and instantly export data.
* **Spreadsheet Converter:** Read natively complex spreadsheet binaries (`.xlsx`, `.csv`, `.ods`, `.numbers`) and convert them into clean formats, directly in the client.

### 12. 🎵 Audio Converter
A robust browser-side media encoder leveraging native Web Audio APIs and `lamejs`, loaded
lazily from cdnjs (`<Script src=".../lamejs/1.2.1/lame.min.js">`) — the page needs the
network once to fetch the encoder, never to send audio.
* **Universal Decode:** Drops any modern audio file (`.wav`, `.flac`, `.m4a`) to instantly decode its buffer.
* **Client-side Encoding:** Re-encodes the raw audio into an optimized `.mp3` file, relying strictly on your CPU's client-side processing without uploading the audio file anywhere.

### 13. 🔄 Project Regenerator
The inverse of the File Crawler. 
* It takes an `EVERYTHING.LOG` scrape file (which could be generated by an AI or by the File Crawler) and unpacks it.
* You select an empty destination folder on your hard drive, and the Regenerator uses the **File System Access API** to physically re-create all the folders and write all the files back to your local disk, fully restoring the project.

## 🖥️ Thick — the desktop half

`Thick/main.py` opens `FolderCrawlerApp` (Tkinter) on twelve tabs: **1 Select Folder,
2 File Types, 3 View Logs, 4 Visual Explorer, 5 Regenerate, 6 USB Devices, 7 Web Crawler,
8 PDF to MD, 9 CSV to JSON, 10 JSON to CSV, 11 JSON Format, 12 Pretty Print** — the same
crawl → `EVERYTHING.LOG` / `MAP.txt` → regenerate loop as Thin, plus desktop-only reach
(USB enumeration, PyMuPDF/pymupdf4llm for PDFs, pinned offline on purpose — see
`Thick/requirements.txt`). `run_crawler.sh` runs it with the system `/usr/bin/python3` and
clears `VIRTUAL_ENV` so an editor's venv cannot hijack it. `Thick/Audit/` holds research
notes (Apple TV, Chromecast, DNS, SNMP, browser-native audits) for future pages.

## 🛠️ Architecture (Thin)

* **Frontend Framework:** Next.js 16 (App Router, Turbopack), static export
* **Language:** TypeScript
* **Styling:** Tailwind CSS v4 + shadcn/ui
* **State Management:** Zustand (`Thin/src/store/useAppStore.ts`)
* **Parsing:** web-tree-sitter + tree-sitter-wasms (WebAssembly)
* **Graphs:** @xyflow/react (Visual Explorer), d3-hierarchy (SCOPE Map)
* **Deployment Target:** Static Export (`Thin/out/`) targeting `crawler.like.audio`

There is no backend server. File crawling, parsing, hardware enumeration, network sweeping
and conversions run in the browser sandbox; the two network touches are the Web Scraper's
CORS proxy and the Audio Converter's one-time encoder fetch, both named above.

## 🚢 Deployment

`.github/workflows/` builds `Thin` and FTP-deploys `Thin/out/` to `crawler.like.audio` on
**every push to `main`** (password from the `FTP_PASSWORD` secret). A push is a release.

## 💻 Running Locally

Thick: `Thick/run_crawler.sh` (Linux/macOS) or `Thick/run_crawler.bat` (Windows);
dependencies via `pip install -r Thick/requirements.txt` (or `Thick/installation.py`).

Thin:

1. Install dependencies:
```bash
cd Thin
npm install
```

2. Start the Turbopack dev server:
```bash
npm run dev
```

3. Open your browser to `http://localhost:3000`

## 🤝 Contributing
Since the goal is a 100% backend-free suite, any new auditing functions (like SNMP walks or mDNS browsers) must be designed either as native browser hacks (like the LAN timing attack sweeper) or via an optional lightweight Local Relay WebSocket script for advanced networking.
